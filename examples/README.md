# Examples

`example-project.json` is **EXAMPLE ONLY** fictional data (documentation addresses from 192.0.2.0/24 and 198.51.100.0/24). It holds two recipes: an IE3100 switch managed through an SVI, and an IE3x00 switch managed through a loopback behind a Routed uplink. Both use `{{MGMT_INTERFACE}}` and `{{MGMT_SOURCES}}` (see [docs/USER-GUIDE.md](../docs/USER-GUIDE.md)).

- Safe to open in SwitchCard via **Open project**.
- Card ZIP export stays blocked while the Example flag is set.
- Do not treat this as a verified Cisco configuration.
